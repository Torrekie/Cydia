# Cydia modernization checks

The project continues to use the existing Makefile toolchain.  `make
verify-config` checks the effective device build configuration and the command
lines generated by the Objective-C and Objective-C++ rules.  `make
verify-compile` builds every supported Objective-C object plus the `postinst`
and `cfversion` helper binaries without linking the application.  `make verify`
runs those checks together with the ownership and source-size gates.

The app-owned source-size limit is 1200 lines (`VERIFY_MAX_SOURCE_LINES` can be
overridden for an audit).  This is a migration guardrail: a source above the
limit should be split into a cohesive module before the final gate is green.
Vendored `apt64` and `SDURLCache` sources are excluded from this size check but
remain in the supported ARC compile graph.  The current migration may therefore
leave `make verify` red while `make verify-config` and targeted compile checks
remain useful; the final acceptance condition is a green `make verify`.
